为什么它能播，而很多同类播不出

浏览器比本地播放器严格得多，三个常见坑本项目都填平了

问题表现本项目做法
原生 <audio> 不支持 HLS.m3u8 点了没反应 / 一直转圈内置 vendored hls.js，自动识别走 HLS 分支
跨域（CORS）控制台一片 Access-Control-Allow-Origin 报错服务端代理，所有请求同源，浏览器从不直连
master m3u8 跳 CDN + token四川 / CNR 这类源播到一半断服务端重写整个 m3u8，自行跟随 301/302 重定向

快速部署（飞牛 NAS / 任意 Docker 主机）

复制下面内容存为 docker-compose.yml，一条命令即可运行

# docker-compose.yml
services:
  jiexiang-radio:
    image: ghcr.io/haonanren118/jiexiang-radio:latest
    container_name: jiexiang-radio
    restart: unless-stopped
    ports:
      - "8081:8080"
    volumes:
      - ./data:/data
    environment:
      - TZ=Asia/Shanghai
      - UPSTREAM_TIMEOUT=15000
# 启动后浏览器打开
docker compose up -d
# → http://<你的主机IP>:8081

本项目需在自有 Docker 主机（如飞牛 NAS）部署后访问，暂无公共演示站点。本地构建零第三方依赖，几十秒完成。

三步开始

1

克隆仓库

git clone 项目到你的 Docker 主机。

2

docker compose up

一条命令拉起容器，端口 8081。

3

搜索 / 订阅

全球电台搜索、导入订阅源，开始收听。
